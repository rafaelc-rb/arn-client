# Aranet Goiás

Aplicativo móvel para acesso à plataforma **Aranet GO** - Sistema de gestão para provedores de internet.

## 📱 Sobre o App

Este aplicativo funciona como um **WebView wrapper** que permite acesso móvel à plataforma Aranet Go através do navegador integrado do dispositivo.

### 🎯 Funcionalidades

- **Acesso móvel** à plataforma Aranet Go
- **Interface responsiva** adaptada para dispositivos móveis
- **Navegação otimizada** para touch
- **Suporte a JavaScript** completo

### 🔗 URL de Acesso

O app redireciona para: `https://aranetgo.sgplocal.com.br/accounts/central/login`

## 🛠️ Tecnologias

- **Flutter** - Framework de desenvolvimento
- **WebView Flutter** - Plugin para exibição de conteúdo web
- **MVVM** - Padrão de arquitetura

## 📋 Requisitos

- Android 7.0+ (API 24)
- iOS 11.0+
- Conexão com internet

## 🚀 Instalação

1. Clone o repositório
2. Execute `flutter pub get`
3. Execute `flutter run`

## 📦 Build

### Android
```bash
flutter build apk --release
```

### iOS
```bash
flutter build ios --release
```

## 🧪 Testes

```bash
flutter test
```
